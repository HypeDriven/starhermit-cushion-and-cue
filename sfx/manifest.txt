# Cushion & Cue — SFX manifest (canonical). One clip per line:
# file | event id (CCAudio method / playSfx key, js/audio.js) | description of the sound | usage context
# Clips: MOSS-SoundEffect v2.0, 48 kHz mono Opus 96 kbps VBR, loudness-normalised (-20 LUFS), 100 steps.
# js/audio.js reads sfx/manifest.json for the file→event binding, picks a variant per event with the seeded AV stream,
# and falls back to WebAudio synthesis while a clip is loading or if it fails. Buses: effects (impacts, UI), voice (chimes,
# hint), music (fanfares, achievement), ambience (hall loop). Every clip below is on disk and bound to a live event.
